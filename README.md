# C-PROJECT
THE SMART PHYSICS AND MATHS TOOLKIT IS A CONSOLE-BASED, MENU DRIVEN INTERFACE THAT ALLOWS USER TO PERFORM BASIC PHYSICS AND MATH RELATED CALCULATIONS. THIS TOOLKIT CAN BE REALLY HELPFUL FOR STUDENTS ESPECIALLY WHEN THEY WANT TO CONFIRM THEIR ANSWERS, THEY  CAN GO THROUGH THIS TOOLKIT. THIS TOOLKIT ENABLES USER TO PERFORM THEIR CALCULATION IN THE SIMPLEST WAY BY JUST INPUTING THEIR VALUES. THIS CODE INCLUDES MODULAR FUNCTIONS, CONDITIONAL STATEMENTS(TO KEEP THE CODE RUNNING SMOOTHLY UNTIL THE USER WANTS TO EXIT) AND CONDITIONAL STAEMENTS (TO ENABLE USER TO MAKE CHOICES). THIS PROGRAM IS COMPLETELY BEBINNER FRIENDLY AND REALLY EASY TO USE.
